Motor de inteligencia

MODO SIN IA ACTIVO · Todas las funciones actuales funcionan sin claves ni créditos de inteligencia artificial.

No se solicitan claves en el navegador. Los proveedores futuros se configurarán en un backend seguro. Este MVP no utiliza IA para inventar necesidades.

Persistencia y copias de seguridad

Los registros se guardan exclusivamente en el almacenamiento local de este navegador; no se sincronizan entre dispositivos. Exportá regularmente un JSON como backup.

Piloto personal sin autenticación ni base de datos central. No almacenes datos privados o sensibles; no uses este enlace como CRM compartido hasta incorporar login y PostgreSQL.
